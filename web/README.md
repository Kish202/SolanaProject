# Frontend

Next.js app for the Solana trade backend: wallet connect, live prices, gas-free swaps, and trade history.

```bash
cp .env.example .env.local   # point NEXT_PUBLIC_API_URL at the backend
npm install
npm run dev                  # http://localhost:3000
```

Deployed on Vercel with **Root Directory** set to `web`. See `../docs/DEPLOY.md`.
